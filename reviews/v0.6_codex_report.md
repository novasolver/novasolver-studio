# NovaSolver Studio 0.6 implementation report

Branch: `v0.6`; worktree: `studio_06`. No changes were made to the main checkout.

## Implementation by specification section

### 0. Ground rules

Read the complete specification, its inherited ground rules and the listed implementation files before editing.
Reused the existing store/history, worker/progress, sparse solver, command/MCP, export and UI patterns.
No runtime dependencies were added. New user-facing keys are present in English, Japanese and Chinese with
identical key sets. Local solver data, build helpers and logs are under ignored `.tmp`.

### 1. Contact

- Added editable, undoable per-interface bonded/frictionless/frictional/no-separation settings, Coulomb
  coefficient and signed interference/gap. Absent contact settings preserve the original bonded mesh and solver.
- Added cached run-time splitting of coincident interfaces, including exterior face connectivity and bonded
  junction connectivity. The higher body tag receives duplicated nodes for a two-body interface.
- Positive tri6 dual areas use A/12 at corners and A/4 at midsides, normalized by curved-surface quadrature.
  Nodal pressure is integrated into equilibrium through the consistent surface mass matrix. This avoids
  confusing zero consistent corner force with zero corner pressure in a uniform quadratic patch.
- Added a coupled semismooth normal/Coulomb active-set solve, exact bilateral normal constraints, mechanism
  detection, direct and AMG-based sparse solve paths, gap/slip/status fields, interface forces, complementarity
  and force/moment balance metrics. The active-set scaling is not a physical contact penalty.

### 2. Nonlinear mechanics

- Added incremental total-Lagrangian tet10 mechanics, consistent material/geometric tangents, dead loads and
  analytic follower-pressure tangents. Large elastic deformation uses St. Venant–Kirchhoff elasticity.
- Added small-strain J2 radial return with isotropic hardening, elastic unloading and isolated trial history.
  The entered post-yield tangent H is converted to plastic hardening modulus E H/(E-H). A B-bar volumetric
  projection avoids artificial plastic incompressibility locking. Finite-strain J2 is explicitly refused.
- Added logarithmic compressible neo-Hookean energy and an element-mean volumetric treatment, plus rubber,
  TPU and silicone presets. The homogeneous reference solves the lateral zero-stress condition numerically.
- Added displacement control, load paths, predictor steps, automatic cutback, retained converged snapshots,
  progress, memory estimates, true-scale deformation, strain/rotation advice and material readiness checks.
  A failed solve retains its last converged state and leaves the converged gate false.
- Contact, thermal strain and nonlinear mechanics share the same equilibrium iteration. Thermal body
  temperatures can be supplied independently.

### 3. Templates and explicit interpretation choices

Added all seven templates with analytic/homogeneous reference cards and mesh-study quantities.

1. **Thermal sign correction:** heating the ring expands its bore and opens contact. The equivalence test cools
   the ring by delta/(alpha b); a separate test checks that heating opens it. This is a deliberate correction
   to the wording in section 7.8, not a reversed expansion coefficient.
2. **Beam support departure:** the two beam templates use an explicit `beam-clamp` role. It fixes axial
   displacement over the section and transverse translation/torsion at neutral-axis points while permitting
   lateral strain. A fully fixed 3D end confines Poisson/plastic flow and changes the classical beam answer.
   The template descriptions and GUI help disclose this support; the original `fixed` role is unchanged.
3. **Plastic unloading:** returning total strain to zero after yielding causes reverse yielding. The bar path
   includes the zero-force unloading checkpoint before returning to zero displacement. Residual plastic strain
   is checked at that checkpoint and against the peak plastic history.
4. **Friction patch assumption:** the friction benchmark uses nu = 0 to obtain the stated uniform all-stick /
   all-slip patch. This is disclosed in its template description.
5. **Mesh:** long beam/bar benchmarks use conforming directional tet10 grids, avoiding an isotropic mesh whose
   length resolution is dictated by the thin section. This changes only the new templates.

### 4. GUI

Added contact lists, bulk editing, interface selection/highlighting and badges; nonlinear analysis/settings;
effective body material models and hardening inputs; nullable displacement components; step slider/playback;
load–displacement chart and CSV; contact/plastic fields and step-aware section/probe requests. Existing tokens,
controls, typography and semantic viewer colours are reused.

**Visual verification remains incomplete.** Computer use stopped because it could not establish the browser

No visual inspection is claimed from compilation or component tests.

### 5. MCP, commands and exports

Extended update documentation and round-trip payloads for contacts, nonlinear settings, models and displacement
conditions; interfaces and effective settings appear in geometry/case responses. Added step-aware rendering and
probing, contact/plastic quantities, interface status/force summaries and the full curve. MCP remains 24 tools.
Exports include per-step VTU files with a PVD collection, curve CSV, and contact/material/curve report sections.

### 6. CalculiX

Added surface contact decks with stated linear contact stiffness, clearance/interference and friction; nonlinear
elastic stepping; small-strain plastic tables; displacement constraints and follower pressure. Contact pressure
is recovered from free-node equilibrium, excluding support reactions. Actual displacement/stress/plastic frames
are parsed rather than synthesizing results.

Explicit final-run refusals: logarithmic neo-Hookean energy (CalculiX uses a different compressible law),
finite-strain plasticity, no-separation, distributed springs, reversal paths and combined nonlinear/contact
step output. These combinations use the built-in solver or receive a clear unsupported-feature error.

## Fixes

All twelve items in `reviews/v0.6_fixes_brief.md` are addressed below. Validation above supersedes the
previous unfinished validation. The remaining delivery check is Claude's standard frontend build outside
this sandbox; the earlier screenshot verification limitation remains disclosed in section 4.

1. **Large-deformation contact:** readiness, the built-in solver and the CalculiX compiler refuse any
   non-bonded interface with large deformation using the same translated small-sliding/small-rotation message.
   Documented in `docs/CONTACT_NONLINEAR.md`. Regression: `test_fix01_contact_large_deformation_refused`;
   the previous thermal/contact test now asserts this required refusal instead of accepting finite rotation.
2. **Modal supports:** zero prescribed components become modal constraints in both solvers; the built-in K
   includes the existing distributed spring stiffness, including its effect on rigid-mode counting. Non-zero
   prescribed components are ignored with readiness/results warnings. CalculiX continues to refuse springs
   explicitly. Regression: `test_fix02_modal_displacement_and_springs` checks frequencies, deck DOFs and warnings.
3. **Spring units:** added stiffness factors N/m = 1 and N/mm = 1000. `NumberInput` refuses unsupported selector
   and typed unit changes. Regression: `frontend/tests/v06-fixes.cjs`, included in `npm test` through the existing
   boundary-input test entry point; checks both conversion directions and actual component commits.
4. **Body temperatures:** uniform body overrides now supply per-element/Gauss-point initial strains to both
   assemblers. Shared-node temperatures cannot overwrite another body; displayed nodal temperatures are averaged.
   CalculiX explicitly refuses this per-element temperature input rather than writing an incorrect nodal deck.
   Regression: `test_fix04_body_temperature_order_and_element_strain` checks reversed input order, both assemblers,
   and static worker field output.
5. **Material presets:** selecting a preset replaces model, hardening and yield fields from the new preset,
   with model defaulting to linear and H defaulting to E/100. Selecting custom retains the explicit law.
   Regression: `test_fix05_preset_replaces_constitutive_fields` (steel, rubber and TPU).
6. **CalculiX history:** reference evaluation receives the parsed curve and snapshots; missing history makes
   limit-load verification explicitly unavailable. Regressions: `test_fix06_collapse_reference_missing_history`
   and `test_fix06_calculix_passes_parsed_history` (history present/absent). The enabled real press-fit comparison
   additionally exposed a pre-existing tet10-ordering error during reaction recovery; canonicalizing the Gmsh
   elements fixed it. The actual CalculiX comparison now passes.
7. **History memory:** validate at most 50 finite path fractions, each with absolute value <= 100. Estimate
   increments from total path travel and the smallest cut-back, bounded by the storage cap. Online thinning
   keeps at most 200 snapshots, matching curve/residual records and always retaining the last state; the predictor
   keeps its own previous displacement. Regressions: `test_fix07_path_validation` and
   `test_fix07_history_cap_and_memory_estimate`.
8. **Zero-only path:** initialized history and a translated `err.nonlinear_empty_path` validation error replace
   the uninitialized-variable crash. Regression: `test_fix08_zero_path_is_validation_error`.
9. **Collapse preview:** force-controlled perfectly plastic runs stop when a cut-back would fall below 1/64
   of the initial increment or the load-direction tangent falls below 1% of its initial value. Divergence
   guards stop three successive residual increases, a 1000-fold increase, stalled residuals, or a failed line
   search. These plastic-collapse guards preserve the elastic large-deformation Newton transient. The normal
   collapse grid is 32 x 2 x 6, retaining all longitudinal divisions; grid changes invalidate its mesh cache.
   Last converged load: **1280.47 N**, reference **1250.00 N**,
   error **+2.438%**. Results say "limit load reached", retain the last state, and keep the
   converged gate false. Regressions: `test_fix09_divergence_detection`, the existing collapse/divergence tests,
   and the seven preview fixtures, which now each assert a runtime under 120 s.
10. **Progress:** nonlinear progress is the converged load fraction, bounded to 0–100%, including during
    failed attempts; remaining-time estimates are omitted. Regression:
    `test_fix10_progress_reports_converged_fraction_without_eta` and the history test's progress callback checks.
11. **Self-equilibrated results:** omit net reaction when applied force is zero to absolute/relative numerical
    tolerance; contact cases show transmitted normal interface force instead (the largest interface force when
    there are several). Regression: `test_fix11_self_equilibrated_cards` checks press-fit and explicit round-off.
12. **Completed validation:** real counts, elapsed times and the build restriction are recorded above. All
    backend checks use the requested Python, this worktree's PYTHONPATH and LOCALAPPDATA, and BLAS/OMP/MKL = 1.
