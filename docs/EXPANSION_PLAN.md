# NovaSolver 拡張計画（2026-10-27）

電磁気・1D・CAD のどれから取り組むか。先に全体像を決め、そこから順番を引く。

## 1. 全体像 — 「AI が操作して、答えを確かめる」工学ソフト群

```
              ┌──────────────── 共通の土台（Studio で完成済み・育てる） ────────────────┐
              │ ケース形式（JSON）・3つの関門（ran / converged / verified）・MCP ツール      │
              │ 日英中・共有書き出し（画像／回転動画）・コミュニティ・計測・セカンドオピニオン │
              └───────────────────────────────────────────────────────────────────┘
   形を作る               3Dで解く（Studio）                      つなげて解く
 ┌───────────┐   ┌──────────────────────────────────┐   ┌──────────────────────┐
 │ AI-CAD     │──▶│ 構造・熱（済）／流れ（済）／電磁気（新）│──▶│ 1D（ブラウザ版・済）   │
 │ （新・薄く）│   │ 連成：電流→ジュール熱→温度→応力      │   │ 部品の特性を3Dから受け取る│
 └───────────┘   └──────────────────────────────────┘   └──────────────────────┘
```

どのソフトも同じ約束を守る。**AI に頼めば条件を置いて解き、答えが確かかを自分で示す。**
この「検証つき」と「AI 操作（MCP）」と「3言語・無料」の組み合わせが、既存の無料ソフト（FreeCAD、FEMM、Elmer、OpenModelica 等）にない差別化になる。

## 2. 候補の比較

| 観点 | 電磁気（低周波） | 1D の拡充 | AI-CAD（薄い層） | 本格 CAD（GUI） | 電磁気（高周波・アンテナ） |
|---|---|---|---|---|---|
| 今の資産の再利用 | **大**（静電場・2D 静磁場は熱と同じスカラー場の FEM） | 大（ブラウザ版あり） | 中（OCCT は Gmsh 経由で同梱済み） | 小 | 小（FDTD は別物） |
| 無料ソフトの空白 | **大**（FEMM は2D・古い、3Dで使いやすい無料品がほぼない） | 中〜大（熱流体連成の無料品が乏しい） | 大（「AI が書く CAD」はまだ黎明） | 小（FreeCAD・Onshape 無料版・Fusion 個人版） | 中（openEMS はあるが難しい） |
| サイトの需要（閲覧の割合） | 6.3%（流体 5.7% と同等） | 2.4%（1ページあたりは高め） | 歯車・機構は1ページあたり最多（158） | 同左 | 電磁気の一部 |
| 検証のしやすさ | **高**（コンデンサ・同軸・ソレノイド等に解析解） | 高（実装済みの検証方式） | 中（寸法・体積で照合） | 低 | 中 |
| 動画映え | **高**（磁力線・磁石・コイル） | 中 | 高（AI がその場で形を作る） | 中 | 中 |
| 期間の目安 | 第1段 4〜6週 | 2〜4週ずつ | 4〜6週 | 年単位 | 2〜3か月 |
| 危険 | 3D 静磁場は辺要素が必要（第2段） | 小 | AI が書くコードの実行＝安全対策が必須 | 規模・競合 | 計算量・検証 |

## 3. 結論 — 取り組む順番

### 第0段（今〜2週間）: 土台を固める
- セカンドオピニオン（Codex の相互チェック）を毎回のリリース前に回す（`.claude/skills/second-opinion/`）。初回は 0.2.2 の全体レビュー。
- 0.2.2 の計測（`/studio/` の DL クリック・共有書き出しの利用）を2週間見て、何が使われるかを確かめる。
- テンプレートと検証ケースの台帳を作る（電磁気を足す前に「1テンプレート＝1つ以上の解析解」の形をそろえる）。

### 第1段（1〜2か月）: **Studio に電磁気（低周波）を足す** ← 最初の本命
1. **静電場**（3D）: −∇·(ε∇V) = ρ。熱伝導と同じ式の形なので、内蔵 FEM をそのまま使える。
   検証: 平行平板コンデンサ（端効果込みは収束で）、同軸ケーブル、球。
2. **2D 静磁場・軸対称**: A_z の式も同じスカラー形（非線形の B-H 曲線つき）。
   検証: 無限長導線、ソレノイド中心の磁束密度、C 型コアのギャップ。
   用途: 電磁石・ソレノイド・モーターの断面・磁気センサ。FEMM の利用者がそのまま来られる。
3. **連成の第一歩: 電流 → ジュール熱 → 温度**（電場の結果を熱の熱源へ）。既存の熱解析に入力するだけで作れる。
- 第2段で **3D 静磁場・渦電流**（辺要素。内蔵で書くか Elmer（GPL）を呼ぶかは第1段の結果で決める）。

**電磁気を最初にする理由**: 今の FEM の再利用が最も大きく、無料ソフトの空白が最も大きく、サイトの需要も流体と同等で、検証できる解析解が豊富だから。磁力線は動画にも強い。

### 第1段と並行（小さく）: **1D の拡充**（ブラウザ版）
- 予定どおり ①ポンプの Q-H 曲線 → ②熱と流れの連成（冷却ループ）→ ③電気の枝。
- **Studio とつなぐ**: 3D で求めたヒートシンクの熱抵抗や管路の圧力損失を、1D の部品の値として渡す
  （「部品は3D、システムは1D」）。電磁気の第1段の後なら、コイルのインダクタンスも渡せる。

### 第2段（2〜4か月）: **AI-CAD（薄い層）**
- 本格的な CAD の画面は作らない。**AI がコード（build123d / CadQuery、OCCT 上で LGPL）で形を書き、Studio が表示・メッシュ・解析する**。
  面に名前を付けて書き出せるので、Blender の三角形より境界条件が正確になる（今の「AI で描く → Blender」の弱点を直す）。
- MCP ツール `build_geometry(script)`: AI が書いたスクリプトを、ネットワークなし・時間制限つき・作業フォルダ外への書き込み禁止で実行する（ここはセカンドオピニオン必須）。
- 寸法を変えて形を作り直す（パラメータ化）までを第2段の範囲とする。

### 当面やらないもの
- **本格的な CAD の GUI**（スケッチ拘束・履歴ツリー・B-rep の直接編集）: 年単位の規模で、無料の強い競合が多い。
  AI-CAD が使われ、利用者から「画面で直したい」という声が増えてから、小さな編集機能から足す。
- **高周波電磁気（アンテナ・導波管）**: 計算法（FDTD）が別物で、検証の手間も大きい。低周波が定着してから openEMS 連携を検討する。

## 4. 進め方（毎段共通）

1. Claude が仕様書（物理・入力・検証ケース・UI）を書く → 実装は Claude または Codex（量が多い部分）。
2. 検証ケースを先に作る（解析解と 1% 以内、収束 GCI）。
3. **セカンドオピニオン**（Codex の読み取り専用レビュー）→ Claude が全件を判定。
4. プレビュー版として早めに出す（0.3 = 静電場、0.4 = 2D 静磁場、…）。共有書き出しと動画で見せる。
