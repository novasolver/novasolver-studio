## 1. High — L-bracket load does not match the advertised problem

**What goes wrong:** Request `l_bracket` with ratios `{h_over_L: 0.6, t_over_L: 0.05, w_over_L: 0.5, r_over_t: 0.5}` and size `{L_mm: 80, F_N: 1000, E_GPa: 200}`. The response says **“wall-fixed, tip load”** and reports approximately **478.94 MPa** and **1.33735 mm**. Those answers represent force distributed across the horizontal top face.

**Why:** `dataset/l_bracket.py:150` applies the total force to the top face extending from `x=t+R` to `L`. For this input, its moment about the flange root is **39,000 N·mm**; a tip force produces **76,000 N·mm**. The dimensional conversion preserves the distributed-load answer, while the title tells the caller it answers the tip-load problem.

**Suggested fix:** Explicitly describe the uniform top-face load, its extent, and the meaning of `F_N` in both the MCP schema and response. Refuse tip-load requests or provide a separately solved dataset for them.

## 2. Medium — Cylinder axial restraint is unspecified

**What goes wrong:** For an open-ended cylinder, request `thick_cylinder` with `{b_over_a: 2, nu: 0.3}` and `{p_MPa: 10, a_mm: 50, E_GPa: 200}`. The tool returns radial displacement **0.00476655 mm ±0.009393%**. The open-ended Lamé solution gives **0.00491667 mm**, about **3.05% higher**.

**Why:** The dataset imposes zero axial displacement at both ends (`dataset/thick_cylinder.py:7`), and `_lame_u()` uses the plane-strain formula. Neither the MCP description nor the returned title identifies that restriction. “Standard supports” does not tell the caller which axial condition applies.

**Suggested fix:** State **plane strain / axially restrained** in the schema and every response. Either expose an axial-condition parameter with supported solutions or explicitly direct other cylinder conditions to a simulation.

## 3. Medium — Cylinder error band excludes a known reference discrepancy

**What goes wrong:** Request `{b_over_a: 2.67126, nu: 0.230158}` with `{p_MPa: 10, a_mm: 50, E_GPa: 200}`. This matches stored point 24 and returns bore hoop stress **13.231 MPa ±0.124%**. The exact Lamé value is **13.25964897 MPa**, a discrepancy of **0.21606%**, outside the stated band.

**Why:** Lines 163–165 trust the stored mesh band and set interpolation error to zero at a stored point. The calculation never checks that band against the available exact cylinder reference. Matching a stored point therefore produces an unjustifiably narrow numerical error claim.

**Suggested fix:** For this analytic family, use the exact solution or bound the reported uncertainty by the measured reference discrepancy. Add tests comparing every stored cylinder point with Lamé, including the published band.

## 4. Medium — Estimate data is missing from desktop packaging

**What goes wrong:** In a frozen Windows release, a valid `instant_estimate("plate_hole", ...)` call reaches `_space()` and raises `FileNotFoundError` instead of returning an estimate. All seven shapes depend on these files.

**Why:** `build_release.ps1:31`–34 includes translations, frontend assets, samples, and integrations, but omits `backend/novastudio/estimate_data`. `--collect-submodules novastudio` collects Python modules, not these JSON resources. The package-data entry in `pyproject.toml` covers wheels, not this PyInstaller command.

**Suggested fix:** Add `estimate_data` to the frozen bundle at `novastudio/estimate_data`. Include a frozen-executable smoke check that requests an estimate.

## 5. Medium — FreeCAD macro paths are not XML-decoded

**What goes wrong:** A configured macro directory `D:\CAD & FEA\macros` appears in `user.cfg` as:

```xml
<FCText Name="MacroPath">D:\CAD &amp; FEA\macros</FCText>
```

`macro_dir()` returns `D:\CAD &amp; FEA\macros`. Installation writes there and can report success, while FreeCAD searches the actual directory containing `&`.

**Why:** The regex extracts raw XML text and passes it directly to `Path`, preserving entity escapes.

**Suggested fix:** Parse `user.cfg` with an XML parser and read the decoded `MacroPath` text. Test escaped characters in configured directories.
