NovaSolver Studio 是在您自己的电脑上运行的仿真软件。从模板或 CAD 文件开始，几次点击即可求解。每个结果都标注“已运行 → 已收敛 → 已验证”，也可以交给 AI 助手来设置和求解。

下载 Windows 版 在 GitHub 查看源码

不只是“算完了”，而是“已验证”

网格太粗或边界条件不对，仿真结果很容易出错。Studio 对每个结果分三步判定。

✓ 已运行→✓ 已收敛→✓ 已验证

自动与教科书解比较

梁的挠度、应力集中、翅片散热、管内流动、圆球阻力等，都会与解析解或文献值比较。

自己的形状用网格收敛确认

没有理论解的形状，会在三种网格上求解，并确认离散误差（GCI）不超过 5%。

危险结果会给出警告

例如应力超过材料屈服强度时，会提示“线弹性分析结果不成立”。

让 AI 助手来求解

Studio 支持 MCP（Model Context Protocol）。对 Claude 等助手说：“固定这个零件的底面，在顶面施加 500 N，并告诉我结果是否已验证。”AI 会设置条件、求解并汇报结果。AI 的操作会实时显示在界面上，便于人工确认。

没有提供通用命令执行工具。AI 不直接编写求解器文件，只填写经过检查的输入项。

快速开始（Windows）

  1. 从 GitHub Releases 下载 zip 并解压（无需安装）。
  2. 双击 NovaSolverStudio.exe，界面会在浏览器中打开。
  3. 结构和传热分析可直接使用（已内置求解器和 CalculiX）。
  4. 流动分析需要将 OpenFOAM®（ESI 版 Windows 安装包，约 200 MB）安装到 %LOCALAPPDATA%\NovaSolverStudio\solvers\openfoam，无需管理员权限。

预览版尚未进行代码签名。若 Windows 显示警告，请选择“更多信息 → 仍要运行”。zip 的 SHA-256 列在 Releases 页面上。
