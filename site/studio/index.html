CADを読み込んで、構造・熱・流れを解く。
答えが正しいかまで、自動で確かめる。

NovaSolver Studio は、パソコンの中で動く解析ソフトです。テンプレートかCADファイルから始めて、数クリックで解けます。結果には「実行できた → 収束した → 検証済み」の判定がつき、AIアシスタントに頼んで操作することもできます。

Windows版をダウンロード GitHubでソースを見る

「動いた」ではなく「検証済み」まで

解析ソフトの答えは、メッシュや条件しだいで簡単に間違います。Studio は結果ごとに3段階で判定します。

✓ 実行できた→✓ 収束した→✓ 検証済み

教科書の解と自動で比較

梁のたわみ、応力集中、フィンの放熱、管内流れ、球の抗力などを、解析解や文献値と比べます。

自分の形状はメッシュ収束で確認

理論解のない形状は、メッシュを3段階に変えて解き、答えの不確かさ（GCI）が5%以下かを確かめます。

危ない結果には警告

たとえば材料の降伏応力を超えたら「この線形解析の結果は成り立たない」と知らせます。

解けるもの

CADファイル（STEP・IGES・BREP）を読み込み、面をクリックして条件を決めます。

解析使い道の例使うソルバ
構造（静解析）ブラケットの強度、たわみ、応力集中内蔵FEM（数秒）・CalculiX
熱（定常熱伝導）ヒートシンク、断熱、フィン内蔵FEM・CalculiX
流れ（内部流れ）配管の圧力損失、流量OpenFOAM®
物体まわりの流れ抗力・揚力、風・水の当たり方OpenFOAM®（壁面層つきメッシュ）
水冷（熱連成）冷却板、水路で冷やす部品の温度OpenFOAM®（流体と固体を同時に解く）

AIアシスタントに頼んで解く

MCP（Model Context Protocol）に対応しています。Claude などに「この形状の底面を固定して、上面に500 Nかけて。検証済みかも教えて」と頼むと、AIが条件を設定して解き、結果を報告します。AIの操作は画面にもそのまま映るので、人が確認できます。

汎用のコマンド実行ツールは持たせていません。AIはソルバの設定ファイルを直接書かず、確かめられた入力欄だけを埋めます。

はじめかた（Windows）

  1. GitHub Releases から zip をダウンロードして展開します（インストール不要）。
  2. NovaSolverStudio.exe をダブルクリックすると、ブラウザに画面が開きます。
  3. 構造と熱は、そのまま解けます（内蔵ソルバと CalculiX を同梱）。
  4. 流れの解析には OpenFOAM®（ESI版 Windows パッケージ、約200 MB）を %LOCALAPPDATA%\NovaSolverStudio\solvers\openfoam に入れます。管理者権限は不要です。

プレビュー版のためコード署名はまだありません。Windows の警告が出たら「詳細情報 → 実行」で起動できます。zip の SHA-256 は Releases ページに載せています。
