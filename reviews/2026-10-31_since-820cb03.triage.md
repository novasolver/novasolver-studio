| 1 HIGH | The version string from latest.json was not validated. `1.0.0/../victim` let `_unpack` delete and refill any folder next to the app, and the version was pasted unquoted into the PowerShell script (code injection; a quote also broke the script, so Studio never restarted) | **Fixed**: versions must match `\d{1,4}\.\d{1,4}\.\d{1,4}` (the notice, the staging folder and apply). | 2 HIGH | Nothing was signed: whoever controls novasolver.jp or the GitHub repo could ship any exe, and zip hosts were any https URL | **Fixed**: latest.json is `{payload, signature}`, an Ed25519 signature over the canonical payload, verified against `PUBLIC_KEY` built into the app (key kept outside every repository, see docs/architecture/secrets-and-credentials.md). A test key and plain-http localhost are accepted only together with `NOVASTUDIO_UPDATE_URL`. `tools/sign_latest.py` writes the notice. `cryptography` is now a declared dependency |
| 3 MED | A user-installed OpenFOAM under `<app>/solvers/` stayed in `.old-*` and was deleted at the next update | **Fixed**: after a successful swap, solver folders the new version lacks move from the old folder into the new one (a failed swap leaves them untouched). Checked in the end-to-end test with a marker folder |
| 4 MED | Running from `NovaSolverStudio.old-x` made the cleanup delete the running app | **Fixed**: updates are refused unless the app folder is named exactly `NovaSolverStudio`, and the cleanup skips the app and staging folders |

| 7 LOW | The 2 % flatness rule hid edges on every flat result (thin plates) | **Fixed**: only for sections (`fieldIsSlice()`) |

| 9 minor | Offline with a cache retried on every check; pre-release tags; the old tab stays on "restarting"; toast de-duplication per origin | Offline: **fixed** (retry after an hour).
