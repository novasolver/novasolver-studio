### High — Boundary conditions move after tolerant fragmentation

**What goes wrong:** In an in-memory `mesh_job` reproduction with two 10 mm cubes separated by 0.05 mm, exact fragmentation identifies `f8` as the outer end face at `x = 20.05 mm`. The fuzzy fallback identifies `f8` as a side face at `y = 0`. A load assigned to `f8` therefore moves to another surface. `check_condition_faces()` passes for both meshes.

**Why:** The fallback changes topology but discards the fragmentation mapping. Faces subsequently receive keys from their new Gmsh tags (`f{tag}`, line 926). Conditions remain keyed by the original tags, and the condition check verifies only that a key exists. The total-volume check cannot detect this reassignment. The fuzzy warning discusses contact stresses without explaining that loads or supports may have moved.

**Suggested fix:** Preserve stable face identities through fragmentation and validate every conditioned face against its original geometry. Reject ambiguous or removed mappings before solving. Apply equivalent identity checks to body materials and contacts.

### Medium — Fuzzy warnings are not attached to their results

**What goes wrong:** Run a convergence study that requires fuzzy meshing while the case has no ordinary volume mesh: the study writes its mesh statistics into private level directories, but the displayed result receives no fuzzy warning. Likewise, remeshing the case can remove the warning from an older fuzzy result or add it to an older exact result.

An in-memory payload reproduction confirmed that changing only the current mesh statistics makes the same saved run gain or lose `fuzzy_mesh`.

**Why:** `payload()` loads the selected run into `jd`, then obtains `fuzzy_mm` through `geometry.mesh_state(case)`, which reads the case’s current `mesh/mesh_stats.json`. `_mesh_for_run()` copies only `mesh.npz`; the fuzzy metadata is not persisted with the run.

**Suggested fix:** Store geometry-change metadata with each run and read warnings from that metadata. Preserve relevant metadata from every convergence level.
