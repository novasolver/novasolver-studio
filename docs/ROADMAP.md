## 公開・普及（構築と並行・ユーザー指示 2026-10-25）

1. **サイト公開**: novasolver.jp のトップページから Studio へリンク。配布・紹介ページを作る（本番SSOTの手順で）。
2. **早期リリース**: 検証途中でも公開し、バージョンを上げながらブラッシュアップ。GitHub Releases ＋ 変更履歴。
3. **各メディアで紹介**: note など。既存の投稿台帳・自動投稿のルールに従う。
4. **訴求点**: MCP連携（AIに頼むと解ける）、手軽さ、物理エンジンと違い**実務で使える**（検証済みの判定つき）。
5. **動画が主役**: Web上の練習問題・既存ベンダーのチュートリアルを実際に解き、結果が劣らないことを示す。
6. **動画の工夫**: Codex の画像生成や Blender の映像から解析対象を抽出 → 実際に解析して応力・流量・熱を求め、「使える」イメージを見せる。UI が自動で動く様子（AI操作）も見せる。
7. **対象を広げる**: 工学者・研究者のものだった CAE を、学生や興味を持った人にも。

判断基準: 新機能は「動画で見せられるか」「初心者がつまずかないか」で優先度を決める。
