## 流体の精度課題（2026-11-06、Flash への流体追加の調査で判明）

- **乱流の急拡大管（d=20 mm、β=0.76、Re=2.4万）**: メッシュ水準で入口圧力が 201 / 155 / 202 Pa（粗い / 標準 / 細かい）。標準メッシュは 2000 反復まで続けても 154.9 Pa で、収束済みのまま違う解に落ちている。k・ω の移流を2次精度にしても変わらない。断面積の差は約 1 %。標準メッシュの解だけ噴流が上下非対称で、外周流速は 0.40 / 0.30 m/s、中心のずれは 0.2 mm。背景格子を 18 → 19 分割にすると 4000 反復で収束せず 208 Pa。対称形状の定常 RANS が、格子しだいで非対称解や振動解に入る。Flash の乱流形状はこれを直すまで入れない。
- **層流の矩形ダクト（dataset/out/rect_duct、80点）**: Shah-London の厳密解に対して fRe が中央値で 3.8 %、最大 7.2 % 低い（データセットの誤差幅は中央値 11 % で、その中には収まる）。原因は四面体の双対メッシュが角の壁せん断を捉えきれないこと。縦横比 4 の1点で、粗い / 標準 / 細かいメッシュの誤差が -12.8 / -6.1 / -2.1 %。同じ点を snappyHexMesh の六面体メッシュで解くと -1.0 / -0.05 / +0.3 %（円管は +3.0 / +1.6 / +0.5 %、双対メッシュは約 -0.5 %）。層流の内部流れも snappyHexMesh に切り替え、失敗したときだけ双対メッシュに戻す（flow3d.py、2026-11-06）。
- 入口圧力は、表示メッシュの節点から拾う方式から、OpenFOAM の patchAverage に変更した（flow3d.py）。上の急拡大管では差は 0.2 Pa で、上の課題の原因ではない。
- **急拡大管の原因と修正（2026-11-06）**: 壁の境界層（addLayers の featureAngle 130）が段差の入隅を回り込み、そこの 15 セルに p 残差の 60 % が集まって SIMPLE が 1.5e-3 で止まっていた。featureAngle 60 にすると層が直角の角で止まり、237 反復で収束、噴流は対称、入口圧力は -203 / -198 / -194 Pa（粗い / 標準 / 細かい、単調）。層流ダクトは fRe -0.67 / -0.03 / +0.32 % で悪化なし。
- **検証例題 sudden-expansion は不合格になった**: 以前の K 0.5595（-0.5 %）は、同じ入隅で収束しないまま非対称に落ちた解の偶然の一致だった。収束した解では K 0.493（-12.4 %）。下流管を 15 D → 40 D に延ばして十分発達した区間で測っても 0.502（-10.7 %）。残りの差は、Re 5,000〜10,000 で上流・下流とも摩擦を Blasius より 10〜20 % 大きく見積もることで、外挿した圧力がずれるため（約半分を説明）。例題の判定は変えず、VALIDATION の「分かっている限界」に書いた。低 Re の乱流摩擦（壁関数と第1層の高さ）は別課題。
