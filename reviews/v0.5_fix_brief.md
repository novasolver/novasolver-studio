# Fix brief — second-opinion findings on 0.5 (from `reviews/2026-10-29_since-9ffe633.codex.md`)

Fix all seven findings in this worktree (branch v0.5). Ground rules are those of `docs/specs/SPEC_0.5_competitive.md` §0.

For every finding, add a regression test that **fails on the current code** and passes after the fix. Put them in
`backend/tests/test_v05_review.py`; the frontend one goes in `frontend/tests/`.

1. **References and extra loads.**
   - An analytic reference must be marked not applicable when the case has a load the formula does not include:
     gravity, rotation, a thermal load, or any role the formula does not model.
   - Check every template's reference function (cantilever, plate-hole, the 0.5 templates and the thermal and
     electric ones if they can take the new loads).
   - Use a single helper, so that new loads cannot be forgotten.
   - The "why" text must say which load prevents the comparison.
2. **Section values with tet10 shape functions.**
   - Evaluate the cut-face values with the quadratic shape functions of the original element at each intersection
     point: no linear sub-tetrahedra values.
   - The click readout on the cut face must use the same interpolation.
   - Test: u_z = x² on a tet10 mesh, cut at x = 0.25, must give 0.0625 to 1e-9.
3. **Role change and retained fields.**
   - When the role changes, revalidate the retained fields. Drop or replace values the new role does not accept
     (for example `direction: "normal"` for `moment`): use the new role's default.
   - Filter the GUI direction options to the role.
   - Test: load → moment does not crash and gets the default direction.
4. **Modal analysis of disconnected parts.**
   - Find connected mesh components, and count rigid-body modes per unconstrained component (6 each; fewer when
     constrained).
   - Request enough eigenpairs. Skip exactly the rigid modes.
   - Test: two separate free blocks → 12 rigid modes skipped; the first elastic frequency matches the single-block
     value within 1 %.
5. **CalculiX thermal stress.**
   - Keep the applied temperature field in the final run's results (`T`, `t_min_k`, `t_max_k`), as the built-in
     path does. `field("temp")`, probes and exports must find it.
   - Test with a fake/mocked CalculiX result if CalculiX is absent, so that the contract is tested everywhere.
6. **Remote-force point.**
   - Every `point` must be exactly three finite coordinates, whatever the input form. A scalar or a wrong length →
     a structured `err.range`/`err.path` error.
   - Test: `"25 mm"` is rejected.
7. **Stale probe response.**
   - Discard probe responses whose case, run or mode no longer match: use a request generation token.
   - Test it in the frontend test runner.

Afterwards:

- Run the new tests, then the full suite (BLAS/OMP threads 1).
- Run `npm run build`. If spawn is refused, run `npx tsc --noEmit` and say so.
- Write `reviews/v0.5_fix_report.md`: per finding, what changed and the test name.
- Commit if git allows; otherwise leave the changes uncommitted.
