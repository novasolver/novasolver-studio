# Triage: review of v0.6.3..HEAD (0.7.0 release)

Codex was unavailable (back 2026-11-04), so the second opinion came from an independent Claude reviewer that read the
code cold (`2026-10-31_since-v0.6.3.claude-independent.md`) and from DeepSeek reasoner
(`2026-10-31_since-v0.6.3.deepseek-reasoner.md`). Every DeepSeek item outside the code changed in this release was
checked against the code by a separate read-only pass (`2026-10-31_since-v0.6.3.deepseek-verify.md`).

## Independent review

| # | Outcome |
|---|---|
| H1 running.json survives a normal exit, so Blender/FreeCAD post to a dead port | **Fixed**: `Instance.unpublish()` on exit (only if the pid is ours); the add-on and macro also check that something answers on the port. Test `test_running_json_removed_on_exit_only_by_its_owner` |
| M1 support singularity one or two elements in still drives the print check | **Fixed**: nodes within about two elements of a fixed face are left out (same reach as `run_worker.support_peak`); test asserts the governing point is away from x = 0 |
| M2 beam-clamp nodes excluded although a beam clamp is not singular | **Fixed**: only `fixed` faces are excluded |
| M3 interlaminar shear ignored | **Fixed**: layer criterion (tension/Z)² + (shear/Z)² = 1 on the layer plane; shear shown in the table and the MCP text |
| M4 nonlinear / plastic / mixed-material cases accepted | **Fixed**: refused when `physics.analysis` is modal/buckling/nonlinear, a material model is not linear, or any body is another material; test covers nonlinear |
| M5 second start after 10 s runs a second server without the lock | **Fixed**: waits up to 120 s, then exits; never starts a second server |
| M6 Edge/Chrome exiting at once leaves nothing on screen | **Fixed**: `desktop.window_started()`; falls back to the default browser. Test `test_window_started_detects_a_browser_that_quits` |
| M7 TPU in the Blender add-on | **Fixed (different reason)**: `tpu` is a preset, but a neo-Hookean one that needs a nonlinear run, so a default (linear) case would stop with an error. Removed from the add-on and README |
| M8 installer offered an all-users install the updater cannot write | **Fixed**: per-user only (`PrivilegesRequiredOverridesAllowed` removed) |
| L1 strength 0 ignored / inf accepted | **Fixed**: 0, negative, inf, NaN → `err.print_check_strength`; tested |
| L2 negative input hides the section | **Fixed**: only positive numbers are sent; invalid fields are marked `aria-invalid` |
| L3 vm and tensor averaged differently | **Fixed**: von Mises computed from the same nodal tensor |
| L4 ties labelled x | Rejected: a tie only happens when all axes are limited by the filament check, and the table shows all three |
| L5 no stale flag for print check | Deferred: the section re-fetches on new results and material change; a stale banner already covers the results view |
| L6 MCP summary lacks support peak and caveat | **Fixed** |
| L7 wall_hook.stl missing from the wheel | **Fixed**: pyproject package data and `tools/build_wheel.py` include `*.stl` |
| L8 numbers-only docstring overclaims | **Fixed**: says sizes and coordinates are still sent |
| L9 test helper never ends after job_status | **Fixed**: polls `state` and reads results with `get_results` |
| L10 integrations open two windows when Studio was not running; FreeCAD blocks the GUI | Deferred (0.7.1) |
| L11 SignPath action pinned to a tag, Python deps unlocked | Deferred: signing is not switched on yet; pin to a SHA when it is |
| L12 `assert` in fetch_build_deps | **Fixed**: explicit checks |
| L13 MSIX MinVersion / version format | Deferred: no Store submission yet |
| L14 examples index and files from different hosts | Deferred (0.7.1): mirror is not served yet |
| L15 version strings | **Fixed**: 0.7.0 |
