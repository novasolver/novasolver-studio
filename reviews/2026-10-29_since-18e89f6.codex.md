### 1. Medium — macOS OpenFOAM fails for non-ASCII workspaces

**What goes wrong:** On macOS, set `NOVASTUDIO_WORKSPACE=/Users/alice/解析` and run an OpenFOAM case. `foam_workdir()` redirects it into `/Users/alice/Library/Application Support/NovaSolverStudio/runs/.../of`. With default OpenFOAM settings, `blockMesh` looks under `ApplicationSupport` instead and fails to find the generated case.

**Why:** The changed scratch location contains a space. OpenFOAM validates `-case` through `fileName::validate()`, which removes invalid characters; POSIX builds disable spaces by default. `shlex.join()` preserves the shell argument but cannot prevent this subsequent transformation. See OpenFOAM’s [case-path handling](https://api.openfoam.com/2406/argList_8C_source.html) and [filename validation](https://api.openfoam.com/2512/fileName_8C_source.html).

**Suggested fix:** Use a separate solver scratch root whose resolved path is ASCII and contains no whitespace or quotes. Redirect paths containing unsupported characters, including ASCII spaces, and retain the `of_location.txt` pointer.

**Validation:** Reproduced the generated scratch path with filesystem writes mocked. **Needs run:** native macOS OpenFOAM reproduction.

### 2. Medium — copied MCP configuration fails after pip/pipx installation

**What goes wrong:** Install Studio using pip or pipx on a machine without uv, launch the GUI, and copy its AI-panel configuration. It specifies `{"command":"uvx","args":["novasolver-studio","mcp"]}`. The MCP client cannot start because `uvx` does not exist, although Studio’s installed Python environment works.

**Why:** Every `config.INSTALLED` installation unconditionally replaces the usable `sys.executable -m novastudio mcp` command with `uvx`. Neither installation method guarantees uv, and the package does not declare it. The AI panel copies this response directly. Even when available, the unpinned uvx invocation can select a different Studio installation.

**Suggested fix:** Generate the configuration using the current interpreter’s absolute path and `["-m", "novastudio", "mcp"]`. Offer uvx separately when available.

**Validation:** Confirmed the unconditional output through an isolated call to `environment_check()`.
