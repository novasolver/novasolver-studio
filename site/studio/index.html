新時代のAI工学設計。

画像生成AIで形を描き、AIがBlenderでモデルにし、NovaSolver Studio が強度・熱・流れを計算します。「描いたものが本当に壊れないか」まで、作る前に分かります。設計から検証までを、無料のソフトとAIでつなぎます。

シミュレーションを、すべての人に

これまで強度や熱の解析は、数百万円のCAEソフトと専門の担当者をそろえた会社のものでした。いまは、AIに頼めば個人でも解析できます。AIが考えた形を、AIが物理の法則で確かめる。アイデアから物理検証までが一続きになり、AIの役割は「文章や絵をつくる」から「ものが本当に成り立つかを確かめる」ところまで広がります。

個人で解析できる

パソコンとAIエージェントがあれば、思いついた形の強度・熱・流れをその場で計算できます。会社でも、個人のものづくりでも。

高級CAEソフトはいらない

ソフトは無料・オープンソース。ライセンス料も、席数の制限もありません。

解析はAIにやらせる

条件の設定、メッシュ、計算、結果の読み取りまで、日本語で頼めます。メッシュを細かくしても答えが変わらないか（検証済みか）は、ソフトが判定します。

描く → 形にする → 確かめる

1つの歯車で、アイデアから強度の確認まで。どの段階もAIに頼めます。

AIで描く

Blenderで形にする

AIがBlenderを操作して、寸法どおりの3Dモデルを作り、STLで書き出します。

Studioに読み込む

書き出したSTLを読み込み、軸の穴を固定して、歯の先に1000 Nをかけます。条件の設定もAIに頼めます。

STL ・ STEP ・ IGES

計算して確かめる

いちばん大きな力がかかるのは歯の付け根で、約100 MPa。メッシュを3段階に細かくして、たわみの答えが落ち着くか（検証済みか）も確かめます。

NovaSolver Studio

CAEで確かめると、何が得か

「なんとなく丈夫そう」を「計算で確かめた設計」に変えられます。会社の製品づくりにも、個人のものづくりにも効きます。

形を最適化できる

AIが形を作り、Studioが評価し、その結果を見てAIが形を直す。これを繰り返すほど、軽く、材料が少なく、それでいて強い形に近づきます。

「何kgまで大丈夫か」を数字で言える

想定する荷重に対する応力・たわみ・強さへの余裕を、メッシュ収束まで確かめた数字で出せます。仕様値を決めるときの根拠のひとつになります。

例：3Dプリントの棚受け（PLA）の背面を固定し、棚に500 N（約50 kg分）→ たわみ 0.15 mm（均質な材料を仮定したモデル）

ほかの商品との違いになる

同じような見た目の商品が並ぶなかで、「解析で確かめた設計」は選ばれる理由になります。カタログ、見積もり、販売ページ、クラウドファンディングで示せます。

試作の回数を減らせる

作って、壊して、直す、の繰り返しを画面の上で先に済ませます。材料費と時間を、本当に必要な試作だけに使えます。

解析の数字は、設計の根拠を示すものです。製品として保証するときは、材料のばらつきや製法の影響も考え、必要に応じて実物の試験と組み合わせてください。

AIアシスタントに頼んで解く

MCP（Model Context Protocol）に対応しています。Claude などに「この形状の底面を固定して、上面に500 Nかけて。検証済みかも教えて」と頼むと、AIが条件を設定して解き、結果を報告します。AIの操作は画面にもそのまま映るので、人が確認できます。

汎用のコマンド実行ツールは持たせていません。AIはソルバの設定ファイルを直接書かず、確かめられた入力欄だけを埋めます。

はじめかた（Windows）

  1. GitHub Releases から zip をダウンロードして展開します（インストール不要）。
  2. NovaSolverStudio.exe をダブルクリックすると、ブラウザに画面が開きます。
  3. 構造と熱は、そのまま解けます（内蔵ソルバと CalculiX を同梱）。
  4. 流れの解析には OpenFOAM®（ESI版 Windows パッケージ、約200 MB）を %LOCALAPPDATA%\NovaSolverStudio\solvers\openfoam に入れます。管理者権限は不要です。

プレビュー版のためコード署名はまだありません。Windows の警告が出たら「詳細情報 → 実行」で起動できます。zip の SHA-256 は Releases ページに載せています。
