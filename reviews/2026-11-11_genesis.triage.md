## Second opinion, Codex (reviews/2026-11-11_since-1aef4d79c2edb8dd35088559f47b54ca4e50c664.codex.md), 8 findings

Each fix has a test in backend/tests/test_genesis_review_1111.py that fails on the code before it (6 fail, 3 pass on
the old HEAD; the 3 passing are the STEP read-back guards).

1. high - structural thermal load ignored by Genesis: **fixed**. precheck refuses `physics.thermal_load` (mode not
   none) for elastic cases with err.genesis_scope / genesis.scope.thermal_load.
2. high - contact pairs bypass the scope check (hertz-cylinder ran as one bonded body): **fixed**. precheck refuses
   `contact_pairs` (genesis.scope.contact_pairs).
3. medium - STL thinner than the analysed part when the cut is below 0.5: **fixed**. surface() maps the density so the
   cut sits at 0.5 and clamps part / outside cells either side of the iso-level. STL / voxel volume, before -> after:
   0.779 -> 1.082, 0.757 -> 1.083, 0.947 -> 0.961, 0.592 (one-cell slab) -> 0.817.
4. medium - STEP of a part with holes holds the hole volume: **rejected**. Reproduced the ring case on all three
   extrusion axes: the written file reads back as 240 mm^3 (correct) in gmsh and in FreeCAD 1.1.4 freecadcmd (one valid
   solid). Codex measured OCC's in-memory mass before the fragment/cut, not the file. Kept as a guard: write_step now
   reads the file back and raises if its volume is more than 1 % off the polygons; a failed write removes part.step.
5. medium - thermal: heated face cut off from the sink still reported as carried (775 K in the void, 2.7 K shown):
   **fixed**. The flux nodes are kept as carry_nodes and clean() checks them like the loaded nodes; warning
   genesis.warn.heat_not_carried, and refine treats it like load_not_carried. Volumetric heat_source is not checked
   (it is spread over the design space by definition).
6. medium - CAD add-ins import an older part's result by file name: **fixed**. find_cases uses file name matches only
   when no case id or hash matches; a send without a case id back (Studio still starting) clears the stored case id
   (FreeCAD Meta, Fusion attribute).
7. low - empty final part crashes with a numpy reduction error: **fixed**. err.genesis_empty (400), translated.
8. low - Genesis panel stale flag only as fresh as the last fetch: **fixed**. genesis_result returns the run's
   revision and the panel compares it with the open case. Checked in the real UI (Playwright, dev server): notice 0
   before, 1 after a PATCH from outside, no page errors.

Found on the way: the empty revisions/ folder of a case had been removed by a temp cleanup and every edit returned
500 (FileNotFoundError on revisions/1.json.tmp). store.save now creates the folder; test added.
