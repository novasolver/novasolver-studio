## 1. --import path is resolved and passed to import_geometry without any check that it is a regular file inside an allowed location; a crafted path (e.g. UNC \\host\share or a device path) is read by the server.
- where: backend/novastudio/__main__.py:70
- scenario: Blender add-on sends --import '\\attacker\share\x.step' -> server opens remote SMB path (credential leak / hang)
- fix: Reject non-local paths (UNC, device names) and require Path.is_file() before import.

## 2. plane_and_blend_labels: 'cut' expression uses operator precedence — `plane_patch[patch[a]] & (patch[a] != patch[b]) | plane_patch[patch[b]] & (patch[a] != patch[b])` is fine, but `own = np.where(plane_patch[patch[a]], a, b)[cut]` picks a when a is plane; if both a and b are plane patches (different patches) it picks a — acceptable.
- where: backend/novastudio/mesh_worker.py:640
- scenario: Two adjacent plane patches both flagged plane: cut True, own=a, other=b; smooth test compares normals of two coplanar patches (dot ~1) so frac counts them as smooth, potentially suppressing a legitimate plane split.
- fix: Exclude pairs where both are plane patches from the smooth-fraction test.

## 3. split_blended_faces rebuilds the model with gmsh.model.remove()/add() and re-adds nodes only to the first surface, but the returned groups are used to build a surface loop; if labels.max()+1 <= len(groups) it returns the original groups while the model was already mutated? No—the early return happens before remove().
- where: backend/novastudio/mesh_worker.py:700
- scenario: labels.max()+1 > len(groups): model is rebuilt; but the caller then does addSurfaceLoop over the new surfaces — OK. However the rebuilt model loses the original surface tags used elsewhere (e.g. key_of mapping in the discrete branch).
- fix: Verify callers only use returned groups; otherwise keep tag mapping.

## 4. fatigue_life_min_away computed via support_peak(nodes, fixed, -f['life']) — support_peak returns 'max_vm_away_pa' which is the max of the negated life, i.e. -min life away; negating gives min life away. But if support_peak returns None for max_vm_away_pa (no away nodes), float(None) raises TypeError.
- where: backend/novastudio/run_worker.py:250
- scenario: Small mesh where all nodes are on the support: support_peak returns max_vm_away_pa=None -> float(None) crash.
- fix: Guard: only set fatigue_life_min_away when the away value is not None.

## 5. sweep_scratch deletes any directory under <scratch root>/runs not referenced by this workspace and older than 7 days, including runs of another workspace/user on the same machine (e.g. shared Public folder).
- where: backend/novastudio/config.py:95
- scenario: Two users share C:\Users\Public\NovaSolverStudio; user A's sweep deletes user B's 8-day-old scratch run still needed for a queued job
- fix: Only sweep runs whose pointer file lives in this workspace, or tag runs with the owning workspace and skip others.

## 6. Recursive _project call passes k2 up to len(Xm); with many misses this re-runs the full O(P*k) Newton loop and can recurse again, causing very long runtimes or recursion depth issues on large meshes.
- where: backend/novastudio/contact.py:175
- scenario: 100k slave nodes, 50k master tris, all miss at k=8 -> k2=50000, full projection over all elements per point
- fix: Cap k2 (e.g. 256) and iterate with growing k instead of one full pass.

## 7. Direct spsolve is now used for all nonlinear runs up to 120k dof regardless of contact; on machines with little RAM this can raise non-MemoryError failures (e.g. SuperLU out-of-memory as RuntimeError) that are not caught.
